# Fresh — шпаргалка (раскладка `macos`)

Версия Fresh 0.5.4, конфиг: `~/.config/fresh/config.json`.
Сочетания собраны из файлов раскладок `default` + `macos` в репозитории Fresh.
Полный список в редакторе — **Shift+F1**, палитра команд — **Ctrl+T**.

После правки `config.json`: `fresh` без файла подключается к фоновому серверу, который держит старый конфиг. Выйти (Ctrl+Q) → `fresh --cmd daemon kill orchestrator` → запустить снова (терминалы внутри Fresh закроются). `fresh ФАЙЛ` (в т. ч. Ctrl+G из Claude Code) работает без сервера и читает конфиг при каждом запуске.

## Файлы и окна

| Клавиши | Действие |
|---|---|
| Ctrl+S | сохранить |
| Ctrl+Q | выйти (возврат в Claude Code после Ctrl+G) |
| Ctrl+O | открыть файл |
| Ctrl+O → имя несуществующего файла → Enter | новый файл по этому пути; на диске появится при Ctrl+S (папка должна уже существовать) |
| Ctrl+N | новый безымянный буфер; дать ему имя — команда «Сохранить как» в палитре (Ctrl+P) |
| Ctrl+P или Ctrl+T | палитра (одно и то же): открывается в режиме команд `>`; сотри `>` — поиск файла по имени, `#` — открытые вкладки, `:` — перейти к строке |
| Ctrl+B | проводник файлов (повторно — назад в редактор) |
| Ctrl+B → Ctrl+N | создать файл в выбранной в проводнике папке: спросит имя, можно с подпапкой (`Dto/Foo.cs`) |
| Ctrl+B → Ctrl+Shift+N | создать папку там же |
| Ctrl+B → Fn+F2 | переименовать файл или папку |
| Ctrl+B → Option+⌫ или Fn+⌫ | удалить файл или папку (спросит подтверждение). Просто ⌫ в проводнике стирает символ поиска |

## Вкладки и панели

| Клавиши | Действие |
|---|---|
| Ctrl+→ / Ctrl+← | следующая / предыдущая вкладка (своя привязка в `config.json`; в macOS должен быть выключен переход между рабочими столами по Ctrl+←/→) |
| Ctrl+Fn+↓ / Ctrl+Fn+↑ | то же без настройки macOS (это Ctrl+PageDown / Ctrl+PageUp) |
| Option+Tab | список открытых вкладок с поиском по имени (то же, что Ctrl+P → Backspace → `#`) |
| Option+W | закрыть вкладку (и вкладку терминала тоже) |
| Option+] / Option+[ | следующая / предыдущая панель (сплит) |
| Option+J | фокус в нижнюю панель (терминал, результаты поиска) и обратно |
| Option+Fn+↑ / Option+Fn+↓ | прокрутить полосу вкладок, если они не помещаются |

Только из палитры (Ctrl+T, затем название):
- **Split Vertical** / **Split Horizontal** — разделить текущую панель на две;
- **Close Split** — закрыть панель;
- **Toggle Maximize Split** — развернуть панель на весь экран и обратно;
- **Increase Split Size** / **Decrease Split Size** — размер панели;
- **Close Tab** — закрыть вкладку.

Мышью: клик по вкладке — перейти, × — закрыть, **+** на полосе вкладок — новый терминал или файл.

Терминалы — обычные вкладки: переключаются, закрываются и разносятся по панелям теми же клавишами. Эти клавиши работают и когда фокус в терминале, без захвата клавиатуры.

## Выделение

| Клавиши | Действие |
|---|---|
| Shift+стрелки | по символам и строкам |
| Option+Shift+← / → | по словам |
| Shift+Fn+← / → | до начала / конца строки |
| Ctrl+Shift+↑ / ↓ | до начала / конца абзаца (нужно отключить Mission Control) |

## Поиск в файле

| Клавиши | Действие |
|---|---|
| Ctrl+F | найти |
| Ctrl+G / Ctrl+Option+G | следующее / предыдущее совпадение (или F3 / Shift+F3, строка поиска не закрывается) |
| Option+N / Option+P | следующее / предыдущее вхождение выделенного |
| Option+C / Option+W / Option+R | в строке поиска: учитывать регистр / слово целиком / регулярное выражение |
| Enter / Esc | перейти к совпадению и закрыть строку поиска / отменить |

Замена в файле — через палитру: **Replace** или **Query Replace** (по одной, с подтверждением y/n/!/q). Ctrl+R в этой раскладке занят повтором.

## Поиск по проекту

| Клавиши | Действие |
|---|---|
| Option+/ | Live Grep: поиск по файлам по мере ввода (ripgrep), Enter — открыть совпадение |
| Option+R | вернуться к последнему Live Grep |
| Option+A | Search and Replace in Project: поиск и замена по всем файлам |
| Option+Enter | в панели замены: заменить все совпадения |

- В поле **Files** панели замены — маски через запятую: `*.cs`, `src/**`.
- В git-репозитории учитывается `.gitignore`, вне git — пропускаются скрытые папки, `node_modules`, `target` и т. п.
- Ищет от папки, из которой запущен Fresh. Запускай `fresh` из папки репозитория (`cd my-repo && fresh`): в `~/Projects` поиск идёт по всем репозиториям сразу, вместе с `bin/` и `obj/`.
- Если Enter в Live Grep открывает пустой буфер — Fresh не нашёл файл по относительному пути (папки поиска и редактора не совпали). Обход: запуск из папки репозитория или Ctrl+P.

## Встроенный терминал

Открыть — из палитры (Ctrl+T): **Open Terminal** (в текущей панели), **Open Terminal to the Right**, **Open Terminal Below**, или сразу в нижнюю панель:

| Клавиши | Действие |
|---|---|
| Ctrl+` (или Option+`) | терминал в нижней панели (Utility Dock); Ctrl+` — своя привязка в `config.json` |
| Option+J | фокус в нижнюю панель и обратно |
| Ctrl+] | выйти из режима терминала в режим просмотра вывода (то же Ctrl+Space, но его часто занимает переключение раскладки) |
| F9 (или Ctrl+\) | захват клавиатуры: все клавиши, кроме F9, уходят в shell, а не редактору |
| Ctrl+V | вставить в терминал |
| Ctrl+клик | открыть путь к файлу из вывода (относительные пути — от текущей папки shell) |

Два режима, видно в строке состояния:
- **Terminal** — ввод идёт в shell. Сочетания редактора (Ctrl+P, Ctrl+T и др.) при этом всё равно перехватываются — для них нужен захват клавиатуры (F9).
- **Terminal (read only)** — просмотр вывода как обычного буфера: стрелки, Fn+↑/↓, Ctrl+Fn+←/→ (начало/конец истории), Ctrl+F — поиск по выводу. Новый вывод сам возвращает в режим терминала.

Ещё:
- Из терминала в редактор и обратно: Option+J (если терминал в нижней панели) или Option+] / Option+[ (если в соседней). Закрыть терминал — Option+W.
- Протянуть мышью по терминалу — выделение (терминал переходит в просмотр), Ctrl+C копирует; Shift+протяжка — выделение, даже если программа в терминале перехватывает мышь.
- **Send Selection to Terminal** (палитра) — выполнить выделенное (или текущую строку) в последнем терминале.
- Когда процесс завершился, вкладка помечается `(exited)`; **Restart Terminal Process** (палитра или индикатор слева внизу) перезапускает в той же вкладке, `claude` — с продолжением прошлого разговора.
- **Shell Command** (Option+|, т. е. Option+Shift+\\) — прогнать буфер или выделение через shell-команду, вывод — в новый буфер; есть вариант с заменой выделения результатом.
- Запущенные процессы при выходе из Fresh завершаются (история вывода сохраняется). Чтобы они жили в фоне — режим демона: `fresh -a`.

## Код (LSP, если для языка он есть)

C# — `roslyn-language-server` (сервер из VS Code, `~/.dotnet/tools`) через прослойку `~/.config/fresh/lsp/roslyn-proxy.py` (без неё Roslyn падает, когда Fresh шлёт файл целиком, например после автозакрытия скобки), стартует сам при открытии `.cs`, корень — папка с `.git`, проекты находит сам (`--autoLoadProjects`). Встроенный плагин `csharp_support` отключён (он ставил корнем папку проекта). Переход к определению по символам из NuGet/BCL открывает декомпилированный код, из него можно переходить дальше. `dotnet restore` сам не запускается — его делает Rider или `dotnet restore` вручную. Запасной сервер — `csharp-ls` (вернуть: `lsp.csharp` в `config.json`, для декомпиляции у него — плагин `csharp_decompiled.ts` + `--features metadata-uris`).

Текст в конце строки — только у ошибок, ломающих сборку (свой плагин `error_lens.ts`); у предупреждений и рекомендаций текст — по Option+K. Ошибки и предупреждения: компилятор + анализаторы Roslyn из пакетов (StyleCop `SA…`, Sonar `S…`, .NET `CA…`/`IDE…`) с уровнями из `.editorconfig` CodeStyle. Инспекций ReSharper/Rider нет. Подчёркивание в коде, значок у номера строки; Option+K на подчёркнутом — текст ошибки; Option+. — исправления и рефакторинги (курсор ставить **на подчёркнутое место**, а не просто на строку), есть «Исправить все» и настройка уровня правила; Ctrl+' / Ctrl+; (или F8 / Shift+F8) — следующая / предыдущая ошибка; палитра → **Show Diagnostics Panel** — список по файлу. Первая загрузка решения идёт с минуту: спиннер у индикатора **LSP** в строке состояния, клик по нему (или палитра → **LSP: Server Status**) — статус, перезапуск, лог. Запустить вручную — палитра → **Start/Restart LSP Server**.

## Где сочетания могут не сработать

- **Ctrl+стрелки** занимает macOS (Mission Control). Освободить: Системные настройки → Клавиатура → Сочетания клавиш → Mission Control, снять Mission Control (Ctrl+↑), окна программ (Ctrl+↓) и переход на пространство влево / вправо (Ctrl+← / Ctrl+→). Рабочие столы и Mission Control останутся на жестах трекпада и F3. Сочетания Ctrl+Fn+стрелки и Ctrl+Option+стрелки macOS не трогает.
- **Ctrl+Space** часто переключает раскладку в macOS — тогда автодополнение не откроется.
- **Option+клавиша** работает только с **левым** Option (`macos-option-as-alt = left` в конфиге Ghostty) и на английской раскладке. Правый Option + `, E, U, I, N в ABC — «мёртвые» клавиши (ждут букву для символа с ударением), до Fresh ничего не доходит.
- **Cmd-сочетания** почти все забирает терминал (cmux или Ghostty: поиск, сплиты, вкладки и т. п.). Работают: Cmd+←/→ (как Ctrl+A/E), Cmd+⌫ (как Ctrl+U), Cmd+V. Копировать — Ctrl+C.
- Непонятно, что приходит от терминала, — **Help → Debug Keyboard Events**.
